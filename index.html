PROJECTS

Workout-Tracker

I made this project to enhance my skills in MERN stack. When I workout, I like organization and keep tracking my scores. Inspirated from the app ‘Strong’ I implemented the basic functionality focusing on workout logging, progress tracking, and clean, user-friendly design.

Tech stack: React, Express.js, MongoDB, Node.js, TailwindCSS

Physio-Web-App

This is a Full-Stack Project for my univerity assignment. As a former physiotherapist I wanted to build a physio web application for clients that can book an appintment with me. A brutalistic desing allows the users to easily navigate through each booking section and receive a confirmation email upon booking.

Tech stack: React, Node.js, Express.js, MySQL, NodeMailer

Habit-Tracker-Python

I developed a Habit Tracker in Python that provides seven key functions for managing habits, including adding, deleting, modifying, and checking consistency. This project strengthened my algorithmic thinking and enhanced my problem-solving skills through practical implementation.

Tech stack: Python, JSON

Airbnb-Clone-MySQL

This project is an Airbnb Clone Database built with MySQL. The database was carefully designed using proper normalization techniques and an ER diagram created in Figma. A key feature of the system is its ability to calculate revenues and commissions for specific properties within a given booking period, making it both practical and scalable.

Tech stack: MySQL

Flashcards-Python

Inspired by the flashcard app Anki and my passion for learning vocabulary, I built a free command-line flashcard application with unlimited deck creation. The app allows users to create decks of unlimited cards and practice either the front or back side. If the user answers correctly, the card reappears after 5 days; otherwise, after 5 minutes—implementing a basic spaced repetition functionality.

Tech stack: Python, JSON
